## How the footage was made

- **Terminal scenes (s02–s09)** are [VHS](https://github.com/charmbracelet/vhs) recordings. VHS starts a real `bash` shell, types each command, and records the shell's actual output. The tapes are in [`tapes/`](tapes/) and are generated by [`build_video.py`](build_video.py).
- **Fresh outputs.** Before recording, the build deletes `artifacts/`. Every file the video shows is created during the recording itself: `scan.csv` in s04, and `define_like_filled.xlsx` in s07, which s08 and s09 then read.
- **The workbook scenes** (s08, s09) open the generated `.xlsx` with `scripts/show_sheet.R`, which uses readxl to print the cells. No spreadsheet application was installed on the recording machine, so the workbook is shown as cell text in the terminal, not as an Excel window.
- **Cards and captions** (s01, s10 and the bottom caption bar) are HTML rendered with headless Chrome. They are the only non-recorded visuals.

## Editing and timing

- **Hidden step.** Each tape has one hidden setup line: `export PS1='$ ' PS2='> ' && renice -n 15 -p $$ >/dev/null && clear`. It shortens the prompt, lowers the CPU priority of the typed commands so the recorder isn't starved, and clears the screen. It does not change any command's output.
- **Edits.** A 0.3 s fade in and out on each terminal scene, a 0.6 s fade on each card, and the caption bar composited below the 1920 × 950 terminal. Nothing was cut out of the middle of a scene.
- **Speed.** Nothing is sped up. VHS drops frames when the machine is overloaded, which would make a clip play faster than the session actually ran. The build therefore compares each recording's duration with the time the session should take (typing at 15 ms per character, plus the scripted pauses) and **aborts if the ratio is outside 0.90–1.35**. An earlier attempt was rejected this way at a ratio of 0.45, during a period of heavy system load.

## Exact commands shown (in order)

```bash
cat -n examples/valid/makeadae.sas | sed -n '19,37p'
cat -n examples/valid/makeadsl.R | sed -n '9,22p'
cat -n examples/valid/makeadsl.R | sed -n '47,49p'
./bin/defxbridge scan --source examples/valid --spec examples/spec.csv --out artifacts/scan.csv | head -n 24
./bin/defxbridge validate --source examples/valid --spec examples/spec.csv
cat examples/invalid/unknown_variable.R
./bin/defxbridge validate --source examples/invalid/unknown_variable.R --spec examples/spec.csv; echo "exit code: $?"
./bin/defxbridge export --source examples/valid --spec examples/spec.csv \
  --template examples/define_like_template.xlsx --out artifacts/define_like_filled.xlsx
scripts/show_sheet.R artifacts/define_like_filled.xlsx Methods --cols ID,Type,Description,"Expression Code" --max 6
scripts/show_sheet.R artifacts/define_like_filled.xlsx PreserveMe
scripts/show_sheet.R examples/define_like_template.xlsx Variables --where Variable=AERELFL --cols Dataset,Variable,Origin,Method
scripts/show_sheet.R artifacts/define_like_filled.xlsx Variables --where Dataset=ADAE --cols Variable,Origin,Method,"Developer Notes"
```

The shell comment lines typed before some commands (`# The SAS program: ...`) are left out of this list.

## Manual steps

None. `python3 demo/build_video.py` produced the whole video. It was reviewed by extracting a frame near the end of every scene and reading each one. Known cosmetic issue: in s09 the last command is 5 characters wider than the terminal and wraps.

## Privacy check

The prompt is `$ ` with no username, host or path. Every path shown is relative to the repository. VHS renders a headless terminal, so no desktop, notifications or other windows can appear. The only personal detail is the author's name on the title card. All data shown is synthetic.
